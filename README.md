# React Learning

A structured record of my React learning journey: concepts, best practices and small projects.

This repo covers only some React concepts and is not a complete course or app.

## Projects and topics

| Folder | What I practiced |
| --- | --- |
| `01vitereact` | Setting up a React app with Vite, project structure, JSX, creating components |
| `02counter-project` | `useState` hook, state updates, event handling, how React updates the UI |
| `03tailwindandprops` | Tailwind CSS setup and styling, props, reusable components |
| `04background_changer` | `onClick` events, passing functions, changing UI with state |
| `05password_generator` | `useCallback`, `useEffect`, `useRef`, building a small real-world app |
| `custom-react` | How React works behind the scenes: building a custom render function and element objects |

## Concepts covered

- Vite setup
- JSX
- Components
- Props
- `useState`
- `useEffect`
- `useCallback`
- `useRef`
- Event handling
- Tailwind CSS
- How React works internally (custom React)

## How to run

Go into any project folder and run:

```bash
npm install
npm run dev
```
